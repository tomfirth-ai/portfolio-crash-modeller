# Data licences

The code in this repository is released under the [MIT licence](LICENSE). That licence covers code
only. It does not cover data.

## Committed data

None yet. Every series committed in future will have a `SOURCE.md` beside it and an entry here,
recording the publisher, the licence and the exact attribution wording the publisher asks for.
Only freely redistributable data is ever committed.

## Data fetched at runtime

Some history is fetched when the app runs and is never stored in this repository, because its
publishers allow use but not redistribution. The app's Data status page lists these sources and
checks that each one can be reached.
